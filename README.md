🧮 Desafio 01 — Criando uma Calculadora em Python com Inteligência Artificial
Objetivo
O primeiro desafio consistiu em utilizar o Google AI Studio para gerar uma calculadora simples em Python, capaz de realizar as quatro operações matemáticas básicas: adição, subtração, multiplicação e divisão.
A proposta foi explorar o código gerado pela Inteligência Artificial e compreender como os conceitos fundamentais da programação são aplicados na construção de uma aplicação funcional.
O que foi desenvolvido
Foi proposta a criação de uma calculadora que recebe dois números e permite escolher uma operação matemática para, em seguida, apresentar o resultado correspondente. Durante esse processo, o foco esteve na compreensão da estrutura do código, no funcionamento das operações e na maneira como cada instrução contribui para a execução do programa.

🛠️ Desafio 02 — Evoluindo a Calculadora com o Google Antigravity
Objetivo
O segundo desafio teve como objetivo dar continuidade à aplicação desenvolvida anteriormente, utilizando o Google Antigravity como ferramenta de apoio para analisar, modificar e aprimorar o código existente.
Diferentemente do primeiro desafio, que teve como foco a criação de uma calculadora em Python com o auxílio da Inteligência Artificial, esta etapa enfatizou a evolução de um projeto já existente, explorando a organização do código, a implementação de novas funcionalidades e a realização de testes para verificar seu funcionamento.
O que foi proposto
O desafio foi dividido em três etapas principais:
Exploração do projeto: analisar os arquivos da aplicação, compreender sua estrutura e identificar como as funções e os componentes do código estão organizados.
Implementação de melhorias: adicionar uma nova funcionalidade à calculadora, ampliando suas possibilidades de uso com o cálculo de porcentagem.
Testes e validação: verificar se a nova operação funciona corretamente e se as funcionalidades anteriores continuam operando como esperado.

✅ Desafio 03 — Criando uma Lista de Tarefas com o Google Antigravity
Objetivo
O terceiro desafio teve como objetivo desenvolver uma nova aplicação utilizando o Google Antigravity: uma lista de tarefas (To-Do List) com interface visual, destinada à organização de atividades pendentes e concluídas.
Após explorar a criação, a análise e a evolução de uma calculadora nos desafios anteriores, esta etapa propôs a construção de uma aplicação diferente, colocando em prática conceitos de desenvolvimento de software, organização de informações e interação com o usuário.
O que foi proposto
A aplicação deveria oferecer três funcionalidades principais:
Adicionar tarefas: permitir que o usuário digite uma atividade e a inclua na lista.
Marcar tarefas como concluídas: possibilitar a identificação das atividades que já foram realizadas, diferenciando-as visualmente das pendentes.
Remover tarefas: permitir a exclusão de atividades que não são mais necessárias.
Além dessas funcionalidades, o desafio incentivou a execução da aplicação, a observação de seu comportamento e a realização de melhorias na interface e no código.
